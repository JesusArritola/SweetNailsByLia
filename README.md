# Sweet Nails by Lia - Landing Page

A modern, elegant landing page for Sweet Nails by Lia nail art business, designed with an athletic aesthetic inspired by strength, precision, and performance.

## 🎨 Estrategia Visual Implementada

Este sitio web sigue una estrategia visual específica que comunica fuerza, disciplina y excelencia atlética aplicada al arte de las uñas:

### **Imagery**
- Fotos en blanco y negro de manos, uñas y clientes en poses atléticas
- Fondos desenfocados que enfocan la atención en los detalles
- Sugerencia: Las imágenes en `modelo/` y `Muestras/` deberían ser reemplazadas con fotos B&W de poses atléticas

### **Color Palette**
- **Primario**: negro puro `#000000`, gris oscuro `#1a1a1a`
- **Acento**: naranja neón `#ff4d00`, plata metálico `#c0c0c0`
- **Fondo**: texturas oscuras (simuladas con patrones sutiles de concreto/metal)

### **Typography**
- **Headings**: Oswald (bold) y Montserrat Black para impacto y fuerza
- **Body**: Roboto Condensed para legibilidad y estilo atlético limpio
- **Espacio**: Poco espacio en blanco, alta densidad informativa

## ✨ Características Principales
- **Hero Section impactante** con gradiente oscuro y acentos neón
- **Navegación clara** entre las 3 secciones principales con estado activo
- **Sección Información** con detalles sobre filosofía athletic, técnica de precisión y estilo que impacta
- **Galería de Arte** responsive que muestra los trabajos reales con filtro B&W y efectos hover
- **CTA destacado** para reservar citas por WhatsApp con gradiente neón/plata
- **Botón flotante de WhatsApp** para contacto directo permanente (esquina inferior derecha)
- **Diseño completamente responsive** que se adapta a móviles, tablets y escritorio
- **Animaciones sutiles** y efectos hover para mejor experiencia de usuario
- **Optimizado para SEO** y rendimiento

## 🎯 Las 3 Secciones Especificadas
1. **Inicio** - Hero section con presentación del negocio y llamado a la acción athletic
2. **Información del negocio** - Detalles sobre la filosofía athletic, técnica de precisión y estilo que impacta
3. **Galería de Arte** - Exhibición de los mejores diseños en formato de cuadrícula responsive con estilo B&W

## 🎨 Paleta de Colores Detallada
- **Fondo principal**: `#000000` (negro puro) con textura sutil de concreto/metal
- **Degradado de secciones**: `#000000` → `#1a1a1a` (negro a gris oscuro)
- **Color primario de acento**: `#ff4d00` (naranja neón)
- **Color secundario de acento**: `#c0c0c0` (plata metálico)
- **Texto principal**: `#e0e0e0` (gris muy claro para contraste sobre negro)
- **Texto secundario**: `#c0c0c0` y `#808080` (grises para subtítulos y menos énfasis)
- **Elementos destacados**: Degradados `#ff4d00` → `#c0c0c0` y bordes/resaltados en neón

## 🔤 Tipografía Detallada
- **Encabezados (h1, h2, h3)**: 
  - Familia: Oswald (para h1, h2) y Montserrat Black (para elementos destacados)
  - Peso: 700-900 (bold to black)
  - Efecto: Letras ligeramente espaciadas para impacto
- **Cuerpo de texto (p, li, etc.)**:
  - Familia: Roboto Condensed
  - Peso: 400-700 (regular to bold)
  - Características: Legibilidad alta, estilo condensado pero claro

## 🚀 Cómo Usarlo Localmente
1. Asegúrate de tener Node.js instalado
2. En la carpeta del proyecto ejecuta:
   ```bash
   npm install
   npm run dev
   ```
3. Abre tu navegador en `http://localhost:3000`

## ☁️ Despliegue en Vercel
1. Sube este repositorio a GitHub
2. Ve a vercel.com y haz clic en "New Project"
3. Importa tu repositorio de GitHub
4. Vercel detectará automáticamente que es un sitio estático y lo desplegará
5. ¡Tu sitio estará disponible en un dominio vercel.app!

## 🔧 Personalización y Próximos Pasos

### **Actualización de Imágenes (Requerido para cumplir con la estrategia visual)**
Para cumplir completamente con la estrategia visual solicitada:
1. Reemplaza las imágenes en `modelo/` con fotos B&W de manos/uñas en poses atléticas
2. Reemplaza las imágenes en `Muestras/` con fotos B&W de diseños de uñas que reflejen fuerza, precisión y rendimiento atlético
3. Las imágenes idealmente deberían mostrar:
   - Manos en posiciones de fuerza (agarre, presión, control)
   - Detalles de uñas con elementos metálicos o geométricos
   - Fondos de gimnasio, equipos deportivos o texturas industriales desenfocados
   - Contraste alto típico de fotografía B&W profesional

### **Actualización de Contenido**
- **Actualizar WhatsApp**: Busca y reemplaza el número `56912345678` en todo el código
- **Actualizar texto**: Modifica los contenidos en las secciones según necesites manteniendo el tono athletic/athletic
- **Actualizar enlaces de redes sociales**: Agrega más íconos en el footer si deseas (Instagram, TikTok, etc.)

### **Modificación de Diseño Avanzado**
- **Modificar colores**: Edita los valores CSS en la sección `<style>` de index.html
- **Ajustar tipografía**: Cambia las fuentes o pesos en las declaraciones de font-family
- **Modificar espaciado**: Ajusta los valores de padding y margin para variar la densidad informativa
